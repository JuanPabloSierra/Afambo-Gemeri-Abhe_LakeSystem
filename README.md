# Afambo–Gemeri–Abhe Lake System

Repository containing scripts and data related to hydroclimatic variability in the Afambo–Gemeri–Abhe lake system used and produced in the article Sierra et al. 2026 subtmitted to Earth System Dynamics.

## Repository structure

├── data/              # Lake model output and processed datasets
├── data/SatelliteImag/              # Contains time series of lake surface (km^2) area for Lakes Afambo, Gemeri, and Abhe, derived from Landsat 8–9 satellite imagery and the Global Surface Water Database, and corrected using the methodology of Mullen et al. (2021).
├── scripts/           # Python scripts

## Data

├── Lake model 
LakeModel_CHIRPS-GLEAM.nc    # File containing time series of lake surface area (m^2) for Lake Abhe and the northern lakes (Afambo and Gemeri), generated by the implemented lake model.

decadal_parameter_results_GR2M-GLEAM-CHIRPS.nc # File containing time series of lake model parameters a and b by 10-year time windows.

├── Hydrological model
